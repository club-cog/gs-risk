# risk-models

Exemplar Bank liquidity, market and counterparty risk models.

The ten production models are written in **Quill** and ran on the RiskDB engine. They are being
migrated to typed, tested Python in `risk_models/`. A model's Python port replaces the Quill
version only once it matches the legacy outputs case by case (parity).

## Layout

| Path | What |
|---|---|
| `legacy/models/*.quill` | The 10 legacy models (source of truth) |
| `legacy/models/lib/*.quill` | Shared Quill libs: `rounding`, `daycount`, `stats` |
| `legacy/data/` | Model inputs: positions, funding, counterparties, rating tables, market data, scenarios |
| `legacy/data/cases/<model>.csv` | Regression cases per model, several as-of dates |
| `legacy/reference_outputs/<model>.csv` | Outputs generated by running Quill. **Never edit by hand.** |
| `legacy/quill_runtime/` | Python interpreter that emulates the RiskDB engine |
| `legacy/MODEL_INVENTORY.md` | Model list, authors, last change, owner status |
| `risk_models/` | Python target. `risk_models/common/` = ports of the Quill libs |
| `tests/runtime/` | Interpreter tests + "references regenerate exactly" |
| `tests/parity/` | Python port vs reference output, case by case |
| `tests/unit/` | Unit tests for the Python code |

## Migration status

| Component | Status |
|---|---|
| `lib/rounding`, `lib/daycount`, `lib/stats` | Ported to `risk_models/common/` |
| 10 models | Not started (parity tests skip until `risk_models/<model>.py` exists) |

## Run it

Python 3.10+.

```bash
pip install -r requirements.txt

# legacy side
python -m legacy.quill_runtime lcr_outflows LCR-002   # one case
legacy/run_all.sh                                     # regenerate all reference outputs
legacy/run_all.sh --check                             # prove committed outputs reproduce exactly

# tests
pytest -v                    # everything
pytest tests/runtime         # interpreter
pytest tests/parity          # parity (skips models not migrated yet)
```

Parity rule: numeric fields must match within an absolute tolerance of `1e-9` (as `Decimal`),
text / dates / booleans must match exactly. See `tests/parity/test_parity.py`.
